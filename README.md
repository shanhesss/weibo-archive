# 微博存档工具

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

拉取任意公开微博博主的全部历史微博，本地查询浏览。

## 启动

- **打包版**：双击 `dist/weibo_archive.exe`（自动打开浏览器）；`weibo_stop.vbs` 停止服务；
- **开发版**：`python weibo_server.py [端口]`（默认 8766），`weibo_start.vbs` 便捷启动/停止；
- **改代码后重新打包**：双击 `rebuild.bat`（自动停旧进程 → 重新打包 → 清理中间文件）。

## 首次使用三步

1. **贴登录信息**：用浏览器登录一个**无关紧要的微博小号**（不要用大号，拉取有被风控的风险）→
   按 F12 → 「网络」里随便点一个请求 → 复制请求头里 Cookie 后面那一整串 → 粘贴到页面顶部；
2. **添加博主**：左侧粘贴博主主页链接（形如 `weibo.com/u/一串数字`）→ 查找 → 添加；
3. 等它拉完。全量拉取在后台慢慢跑（1 万条约半小时），可以关页面，中途重启工具会从断点继续。

## 页面说明

- 左侧每个博主：状态灯 + 进度 + 「拉取新的 / 暂停 / 继续 / 删除」；
- 查询页为卡片网格（3×2 一屏 6 条），卡片内正文超高可滚动；顶部筛选：关键词 + 年份 + 快捷时间区间（今天/昨天/近7天/近30天/今年）+ 微博状态（全部/正常/已删除）+ 起止日期，「清空筛选」一键重置；
- 顶部翻页条支持首页/上一页/输入页码跳转/下一页/末页；
- 点卡片缩略图在当前页打开大图（点图或 ←/→ 切本条微博的下一张，ESC 或点遮罩关闭）；视频点链接去原页面播放；
- 图片经本地代理显示；「登录已过期」亮红灯时：重新登录小号、再贴一次 Cookie 即可（几天到几周一次，属正常）。

## 数据

全部在 `weibo.db`（SQLite 单文件）。每条微博除展示字段外保留接口原始 JSON，
将来要补字段不用重爬。决策背景见 [CONTEXT.md](CONTEXT.md) 与 [docs/adr/](docs/adr/)。

## 易用性验收标准（五条硬承诺）

1. **单页单屏、无 Tab 无弹窗**：所有功能一屏可达；
2. **零术语**：界面不出现 432、containerid、uid 等字眼，状态全部人话；
3. **常用操作 ≤2 次点击**：添加博主 = 粘贴 → 确认；增量 / 暂停 / 继续 = 点一下；
4. **默认即可用**：无必填配置，登录信息未填时只出一条引导，不挡其他区域；
5. **进度一屏可见**：每个博主行上直接看到状态、进度、最后同步时间。

兜底原则：**任何时刻页面出现用户看不懂的状态，视为 bug。**

## 已知限制

- 断点续爬按页码记录，暂停期间博主新发一整页微博时恢复后可能漏几条，下次增量会补回；
- 触发微博访问限制时自动暂停，过段时间点「继续」即可；
- 拉别人账号没有官方接口可用（官方只给 5 条），走的是移动端接口，字段变更需跟进维护。
