# 微博存档工具

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

拉取任意公开微博博主的全部历史微博，在线查询浏览，并可将单条微博 AI 总结后归档到语雀。支持多账号登录，每个账号各自配置微博登录信息、各自管理数据。

> **本分支 `cloudbase-cloudrun` = 云托管产品线（现行线上部署）**：腾讯云 CloudBase
> CloudRun 容器形态，7×24 在线、浏览器直接访问，数据靠对象存储挂载盘快照持久化
> （ADR-0011），与个人其他服务共用备案域名的 `/weibo` 路由。部署见 `deploy/cloudbase/README.md`。
>
> 本仓库两条产品线**永久平行、互不合并**：本地形态（exe / nginx+systemd 自有服务器）在
> **`main` 分支**；exe 打包、vbs 启停、tar 部署链等只在 main 有。

## 功能特性

- **多用户账号**：注册 + 邀请码加入；每个用户的微博 Cookie、语雀令牌、博主与微博数据相互独立；管理员可禁用账号、重置密码、开通归档权限、管理邀请码
- **全量 / 增量拉取**：添加博主即自动抓取全部历史微博，后台运行、断点续爬；之后一键增量拉新
- **定时拉取**：可设定间隔（30 分钟起）自动为所有博主拉取新微博，重启后自动补跑
- **本地查询**：按博主、关键词、日期、归档状态筛选，卡片网格浏览，图片灯箱放大
- **批量操作**：勾选多条批量更新（可修复长文截断）或删除
- **语雀归档**：单条微博一键 AI 总结并同步为语雀文档，形成博主知识库存档；已归档可连同语雀文档一起删除
- **易用性承诺**：登录后主界面单页单屏、零术语；页面出现用户看不懂的状态，一律视为 bug

## 快速开始

首次使用：

1. **注册登录**：向管理员要邀请码 → 注册 → 登录。首次启动会生成内置管理员账号 `admin`，初始密码只在启动日志里显示一次，登录后请立即在个人设置里修改
2. **贴登录信息**：用微博小号打开 m.weibo.cn → F12 → 复制请求头 `Cookie:` 后面一整串 → 粘贴到个人设置（每个用户各存各的）
3. **添加博主**：粘贴博主主页链接（形如 `weibo.com/u/一串数字`）→ 查找 → 添加
4. **等待拉取**：全量拉取在后台慢慢跑（1 万条约半小时），可关页面，重启从断点继续

启动方式：

| 场景 | 操作 |
| --- | --- |
| 日常使用 | 浏览器打开你自己的部署入口 `https://<你的备案域名>/weibo/`（见「部署」节） |
| 本地开发 | `python weibo_server.py [端口]`，默认 8766，绑 127.0.0.1 |
| 冒烟测试 | `python smoke_test.py`（用隔离临时数据库，不碰真实数据） |

## 语雀归档

把微博 AI 总结后同步到语雀：

- 卡片【同步】按钮：AI 总结该条微博并创建语雀文档，挂到博主目录节点下
- 博主行配置「语雀同步目录」（形如 `https://www.yuque.com/账号/知识库/目录`），文档挂在该目录下
- 已归档卡片显示徽标、可按归档状态筛选；批量同步不限条数、批内并发、可随时取消
- 不想留的归档可删：单卡【删档】或批量【删语雀档】，语雀文档一并删除，微博回到待归档
- 文档格式由 `yuque-sync-template.md` 控制，改模板即可调整格式

## 页面说明

- 登录视图：注册 / 登录；个人设置：微博 Cookie、语雀令牌、改密码、申请注销（管理员不可注销）
- 管理后台（仅管理员）：用户列表与状态筛选、禁用 / 启用、归档权限、重置密码、删除用户、邀请码管理、统计
- 左侧博主列表：状态灯、进度、「拉取新的 / 暂停 / 继续 / 删除」、定时拉取设置、语雀目录设置
- 中间卡片网格：关键词、年份、快捷时间（今天 / 昨天 / 近7天 / 近30天 / 今年）、微博状态、归档状态筛选
- 图片经本地代理显示（防盗链）；登录失效亮红灯时，重新登录小号并重贴 Cookie 即可

## 部署（腾讯云 CloudBase 云托管）

服务常驻在腾讯云 CloudBase 云托管（环境 ID 与规格见 `deploy/cloudbase/README.md`，本文档中
以 `prod-xxxxxxxxxxxxxxxx` 占位）。可与个人其他服务共用一个备案域名，按路径路由
`/weibo` → 本服务，入口 `https://<你的备案域名>/weibo/`。运行库在容器本地盘，定期/停止信号时快照到对象
存储挂载盘 `weibo/weibo.db`（新实例启动自动拉回，决策与实测见 ADR-0011）。

操作入口：**读 `deploy/cloudbase/README.md`**（首次部署 / 数据播种 / 日常升级 / 验证清单）。

> 注意：镜像**只装代码，绝不含 `weibo.db`**（数据只走快照通道）；`weibo.db` 也不进 git。

## 数据与隐私

- 数据在 `weibo.db`（SQLite 单文件）：云托管形态下运行库在容器本地盘，每 5 分钟及实例停止时快照到对象存储挂载盘（该快照位文件即线上数据的最近备份，可随时从控制台下载）；运行时产物一律不入 git、不进镜像
- 每个用户的微博 Cookie、语雀令牌按用户存在库里，不入 git；AI 归档中转密钥只在管理后台留掩码显示
- 每条微博保留接口原始 JSON，后续补字段无需重爬
- 拉取走 m.weibo.cn 移动端接口，需要小号 Cookie；触发反爬时工具自动暂停（432 退避）
- 仅供个人学习与存档用途：请使用自己的微博小号（微博可能风控封号，风险自担），抓取内容勿商用或公开转载，勿批量抓取他人私密信息

## 已知限制

- 断点续爬按页码记录，暂停期间博主新发一整页时恢复后可能漏几条，下次增量补回
- 他人账号无官方接口（官方仅 5 条），走移动端接口，字段变更需跟进维护
- 语雀归档依赖管理员在后台配置 AI 中转服务（ADR-0012）；未配置时页面提示「AI 归档功能还没开通」
- 账号需邀请码注册（由管理员开通），不是开放注册
